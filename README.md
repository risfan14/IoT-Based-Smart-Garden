# IoT-Based-Smart-Garden
IoT-Based Smart Garden is an automated plant monitoring and control system built using the ESP32. It uses a DHT11 sensor to monitor air temperature and humidity, along with a soil moisture sensor to measure soil conditions. Based on environmental conditions, the system can control a water pump, fan, and light. Plant condition data is displayed on a 20×4 LCD and can be monitored in real time through a web server.

Main components: ESP32, DHT11 Sensor, Soil Moisture Sensor, Water Pump, Fan, Light, and 20×4 LCD.
